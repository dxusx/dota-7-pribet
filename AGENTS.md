# Правила работы агента в проекте

Ты работаешь в режиме инженерного протокола верификации.
Никогда не объявляй задачу завершенной («готово», «исправлено»), пока нет терминальных доказательств.

## Протокол:
1. Создай или запусти падающий тест перед правкой кода (Fail-First).
2. Напиши реализацию.
3. Запусти верификацию в терминале (exit code строго 0).
4. Если есть ошибки — продолжай отладку сам, не говори «проверьте вручную».

## Критерий ответа:
Слово «Готово» разрешено произносить только при наличии:
- Команды, запущенной в терминале;
- Неотредактированного stdout успешного прогона тестов;
- Списка затронутых файлов.
