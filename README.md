# DOTA 7 PRIBET

Браузерная тактическая игра в духе Dota 2: пошаговые действия, поле 100x100 клеток, очередь инициативы, герои с уникальными способностями, криповые волны, лесные лагеря, башни, троны и Рошан.

Проект распространяется как статическое приложение и работает без сервера или базы данных. Игровое состояние создается в браузере при запуске.

## Возможности

- тактическое перемещение с расчетом маршрута, стоимости времени и доступной дистанции;
- очередь инициативы и ходы по 8 секунд;
- бой с учетом урона, промахов, критов, брони, пробития и возвышенностей;
- 12 героев с портретами, уникальными способностями и подсказками;
- иконки способностей, кулдауны, стоимость маны и времени хода;
- криповые волны трех линий и нейтральные лагеря;
- башни, троны, алтари Bounty-рун и смена логова Рошана по циклу день/ночь;
- интерактивная карта с масштабированием, панорамированием и мини-картой.

## Быстрый старт

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Проверка перед коммитом

```bash
npm run check
```

Команда запускает тесты игровой логики и production-сборку. Отдельно доступны `npm test`, `npm run build` и `npm run preview`.

## Структура

```text
src/
  assets/       локальные портреты героев и иконки способностей
  components/   визуальные React-компоненты, включая карту
  game/         состояние игры, бой, герои, крипы и способности
  map/          генерация карты и данные объектов
```

## Деплой

Каждый push в `main` запускает GitHub Actions workflow, который публикует `dist/` в GitHub Pages. Для локального production-просмотра используйте `npm run build` и `npm run preview`.
