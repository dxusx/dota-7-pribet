# ⚔️ DOTA 2 • 95×95 Pixel Battlefield

Интерактивная тактическая карта **Dota 2** на пиксельной сетке 95×95 с аутентичным интерфейсом (HUD) в стиле Доты, точной 5-цветной палитрой ландшафта, 10 героями, вышками, лагерями крипов, рекой и логовом Рошана.

---

## 🌟 Особенности проекта

### 🗺️ 1. Пиксельная карта 95×95 (Dota 2 Layout)
- **Точная 5-цветная палитра:**
  - `Непроходимое` (`#1a1a1c`) — скалы, внешние границы, лесные массивы, логово Рошана.
  - `Фонтан` (`#384457`) — база Radiant и Dire (+24% HP/ход, +24% мана/ход, очищение).
  - `Хайграунд` (`#8b8788`) — возвышенности баз, плато древних крипов, вард-клиффы.
  - `Граунд` (`#4d7150`) — проходимая земля: 3 мощеные линии (Top, Mid, Bot), поляны крипов.
  - `Вода` (`#8294b6`) — диагональная река со штрафом (-10% к скорости перемещения).
- **3 линии и каменные мосты:** Top, Mid и Bot с каменными мостами через реку.
- **Базы и Троны:** Radiant Древо Жизни (Ancient 💎) и Dire Ледяной Трон (Ancient 🌋) с 4500 HP, защитными вышками T4 и 3 рампами выхода на линии.
- **22 Вышки (Towers):** T1, T2, T3 на всех 3 линиях + пары T4 у тронов, с радиусами атаки (8 клеток).
- **12 лагерей нейтралов + Рошан:** Малые, средние, большие и древние лагеря, а также логово Рошана 👹 в центре реки.
- **Руны в реке:** Руна Воды / Двойной Урон и Руна Богатства / Хаст.

### 🎮 2. Интерфейс 1 в 1 как в Dota 2
- **Верхняя панель (Scoreboard):** счет убийств Radiant (`18`) vs Dire (`14`), игровое время со сменой дня и ночи (`☀️ / 🌙`), 10 иконок героев (5v5) со статусом готовности ультимейта (зеленый кристалл) и полосками HP/маны.
- **Левый нижний угол (Dota 2 Minimap):**
  - Каменная рамка в стиле Доты.
  - 🛡️ **Glyph of Fortification** (Укрепление построек на 6 сек, кулдаун 300 сек).
  - 👁️ **Scan** (Сканирование области, кулдаун 210 сек).
  - Интерактивная миникарта 95×95 с моментальным переходом по клику.
- **Центральная консоль героя:**
  - Портрет героя, круглый бейдж уровня (**LVL 18**), значок атрибута (Сила / Ловкость / Интеллект / Универсальный).
  - Текстурированные полосы HP (с делениями по 250 HP) и маны с регенерацией в реальном времени.
  - Параметры: урон, броня, скорость (в клетках), Сила, Ловкость, Интеллект.
  - 4–6 слотов способностей с горячими клавишами `[Q, W, E, D, F, R]`, стоимостью маны и делениями прокачки.
  - Инвентарь на 6 предметов (*Blink Dagger, BKB, Aghanim, Daedalus, Refresher, Travels*) + Нейтральный предмет 5 тира + Свиток ТП.
- **Правый нижний угол:**
  - Золото героя `🪙 3,850` и индикатор выкупа `🛡️ Выкуп: ГОТОВ`.
  - Кнопка курьера `🐴 [F3]`.
  - Золотая кнопка лавки `🛒 МАГАЗИН [F4]`.

## 🚀 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev

# Сборка проекта
npm run build
```

Открыть в браузере: `http://localhost:5173/`
