# Участие в разработке

1. Создайте отдельную ветку от `main`.
2. Делайте небольшие тематические коммиты.
3. Перед push запустите `npm run check`.
4. Откройте pull request и опишите пользовательский эффект изменения.

Используйте существующие React-паттерны и Tailwind-классы проекта, не добавляйте зависимости без необходимости и не коммитьте секреты, локальные настройки или результаты сборки. Для игровой логики добавляйте тесты.
